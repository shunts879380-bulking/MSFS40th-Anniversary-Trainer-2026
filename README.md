## 🎮 About the Game

Microsoft Flight Simulator is a civilian flight simulation game developed by Asobo Studio and published by Xbox Game Studios. The original PC release launched on August 18, 2020. The 40th Anniversary Edition update released on November 11, 2022, adding helicopters, gliders, historic aircraft, classic airports, and franchise missions.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Microsoft Flight Simulator (2020) 40th Anniversary Edition**. This trainer provides optional control over common flight-simulation parameters, including fuel, crash detection, aircraft positioning, simulation time, and weather conditions. It is designed for practice flights, sightseeing, route testing, and reducing repetitive setup during single-player sessions.

**Target Audience:** Flight simulation enthusiasts, newcomers learning aircraft procedures, virtual pilots practicing approaches, and users who want easier control over long-distance sightseeing or testing flights.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Fuel** — Prevents fuel quantities from decreasing in compatible powered aircraft, allowing extended flights without refueling.
- **Disable Crash Detection** — Prevents the simulator from ending or resetting a flight after an impact.

- **Freeze Aircraft Position** — Locks the aircraft's current position in the simulated world for testing procedures, camera work, and instrument practice.

### 🚶 Movement

- **Slew Position Control** — Supports rapid repositioning while using the simulator's slew-style movement, useful for setting up approaches and exploring locations.

### 🌍 World

- **Freeze Simulation Time** — Holds the current simulation time to maintain a consistent lighting and navigation environment.
- **Lock Weather Conditions** — Keeps the current weather setup stable instead of allowing live or manually configured conditions to change during the flight.

## 📖 Detailed Feature Guide

### Movement & Exploration

Aircraft movement is controlled through the flight model, including pitch, roll, yaw, throttle, trim, landing gear, flaps, and braking. Use the trainer's position controls only when setting up a flight or testing a location. For normal flying, control the aircraft through its cockpit instruments and assigned hardware. Slew-style repositioning is useful for correcting setup mistakes, exploring scenery, and placing an aircraft near a runway or waypoint.

### Tools & Inventory

Microsoft Flight Simulator does not use a conventional player inventory or equipment backpack. Aircraft configuration is handled through the selected aircraft, fuel and payload settings, cockpit controls, avionics, and flight-planning tools. The trainer therefore focuses on aircraft state rather than inventory items.

### World & Environment

The simulator represents a streamed version of the real world with airports, terrain, roads, landmarks, air traffic, time-of-day changes, and weather conditions. Use the world map to select departure and arrival airports, create a route, and choose the starting conditions. The trainer's time and weather controls are best used for repeatable training scenarios, visual approaches, and sightseeing.

### Combat & Weapons

There is no conventional combat system in Microsoft Flight Simulator. The game is a civilian flight simulator focused on aircraft operation, navigation, aviation procedures, exploration, and multiplayer flying. Combat-related trainer functions are not applicable.
